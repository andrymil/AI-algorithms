# AI Algorithms & Machine Learning Fundamentals

> **Academic Collection:** Implementations and experiments with core Artificial Intelligence algorithms.

> **Institution:** Warsaw University of Technology

## About This Repository

This repository contains a collection of fundamental Artificial Intelligence and Machine Learning algorithms implemented in Python. These projects were developed as part of my academic coursework to gain a deep, mathematical understanding of how core AI models operate under the hood, moving beyond high-level framework abstractions.

## Implemented Algorithms

Here is an overview of the modules included in this repository:

- **`ID3_decision_tree`**: Implementation of the ID3 algorithm for building decision trees, utilizing entropy and information gain metrics for classification.
- **`bayes_classifier`**: A probabilistic classifier based on applying Bayes' theorem to datasets.
- **`genetic_algorithm`**: An optimization algorithm inspired by the process of natural selection, mutation, and crossover.
- **`gradient_descent`**: Implementation of the mathematical optimization algorithm used for finding a local minimum of a differentiable function.
- **`minimax`**: A decision rule algorithm used in game theory and AI for minimizing the possible loss for a worst-case scenario.
- **`neural_network`**: A foundational implementation of an Artificial Neural Network, exploring core concepts of network architecture and weights.

## Technologies Used

- **Python**
- **NumPy**

## How to Explore

Each algorithm is contained within its respective directory as a standalone module.

1. Clone the repository:

```bash
git clone https://github.com/andrymil/AI-algorithms.git
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt

```

3. Navigate to the desired folder to explore the code and run the specific algorithm.
